# The Unofficial Skylit Field Guide

- Discord username: rayowa5
- Project identifier: stages-field-guide
- Kind: agent

A knowledge pack for trading agents, not a running program. It distills one month of live Skylit Stages (October 26 to November 25, 2026: 77 transcripts, about 201 hours, 9,530 script-verified quote records) into the lessons the presenters taught the most, written so an AI agent can read them and a human can enjoy them.

## What it does

- [FIELD-GUIDE.md](FIELD-GUIDE.md) is the whole guide in clean Markdown: the ten most-taught strategy ideas with who taught them and how often, the eight discipline rules every presenter repeats, the 71-rule No List grouped as machine-enforceable gates, and what the room teaches about building trading bots.
- [skylit-unofficial-field-guide.pdf](skylit-unofficial-field-guide.pdf) is the same material as a four-page PDF for humans.

Everything is paraphrased; there are no transcripts and no verbatim quotes in this folder. Every count can be traced in my notes to a speaker, a Stage, and a timestamp.

## Skylit surface

- Access: none. This is a static knowledge pack; it makes no API or MCP calls.
- Products discussed: Heatseeker, Atlas, Tempest, Flowseeker, as taught in the Stages.

## How to run

1. Give `FIELD-GUIDE.md` to your agent as reference context.
2. Treat every strategy in it as a hypothesis to backtest with costs, never as a signal.
3. Wire the House Rules and the No List in as hard gates; they need no edge to be useful.
